# SCAE · Sistema de Controle de Almoxarifado e Estoque

Pacote de início do projeto SCAE: protótipo, marca e todo o planejamento.

## Como começar no seu PC

1. Descompacte esta pasta onde quiser guardar o projeto. Exemplo: `C:\Projetos\SCAE`.
2. Abra a pasta no **VS Code** ou no **Claude Code** (app Claude para Windows, aba Code, ou extensão "Claude Code" no VS Code).
3. Na primeira mensagem para o Claude, escreva algo como:

   > Leia o CLAUDE.md e os arquivos da pasta docs. Vamos continuar o protótipo do SCAE de onde paramos.

   O `CLAUDE.md` já explica o projeto, as regras e o plano. O Claude Code lê esse arquivo sozinho toda vez que abre a pasta.
4. Para ver o protótipo, dê dois cliques em `prototipo/scae.html`. Ele abre no navegador.

## O que tem aqui

- `CLAUDE.md`: instruções e contexto para o Claude Code.
- `prototipo/scae.html`: o sistema em protótipo, num arquivo só.
- `marca/`: logo do SCAE em SVG (abre no navegador, no Figma ou no Illustrator).
- `docs/`: plano, arquitetura, regras de negócio, protótipo, marca e histórico da conversa.

## Dica: guardar no GitHub

Para não perder nada, crie um repositório **privado** novo no GitHub, por exemplo `scae`, separado do Almox. Depois peça ao Claude Code: "crie o repositório git desta pasta e envie para o GitHub". Assim cada passo fica salvo.
